# bookmap-layer1-custom-indicators

Open-source custom technical indicators and real-time event aggregation modules for the **Bookmap Layer 1 API** in Java.

## Features
- **Loginov EMA Indicator (`Loginov.java`)**: Real-time Exponential Moving Average calculation with custom event aggregation (`CustomEventAggregatble`).
- **Customizable UI Settings**: Live adjustment of smoothing factor (`alpha`), line color, and line width directly inside Bookmap.
